# Sistema de cadastro

## Modo de uso
```
git clone https://github.com/lsguilherme/sistema-cadastro-javaio.git

Abra UserService e troque o PATH_DIR para a pasta que você quer que seja adicionado os arquivos do usuario em .txt.

Recomendado copiar o path absoluto da pasta clonada e adicionar no final "\\users"

Rode o arquivo Main
```
## Descrição

Sistema de cadastro via terminal, onde o usuário pode: 
- Cadastrar um usuário; 
- Listar usuários cadastrados; 
- Cadastrar pergunta no formulário;
- Deletar pergunta no formulário;
- Pesquisar usuário pelo nome

## Tecnologias

Nesse desafio foi utilizado:

- Orientação a Objetos
- Java I/O
- Streams e lambda
- Exceções
- Boas práticas de código
